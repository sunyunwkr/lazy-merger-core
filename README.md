# lazy-merger-core

Graphics programmer · Clojure and Datomic · open source


## 用法

```bash
cat data.txt | python main.py
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/sunyunwkr/lazy-merger-core.git
cd lazy-merger-core
pip install -e .
```
